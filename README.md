# C.F.H. Alignment Collective — GitHub Pages website prototype v0.2

A complete static site. Upload `index.html`, `styles.css`, `script.js`, `favicon.svg`, and the entire `assets` folder to the **root** of your GitHub Pages repository. No build step is needed.

## Before launch

1. **Contact:** Open `script.js` and replace `hello@example.com` with your real contact email. The form prepares an email in the visitor's email application; it does not transmit submissions itself. Without a real email, the prototype intentionally shows a configuration warning.
2. **Your photographs:** Replace `assets/caroline-hero.svg` and `assets/caroline-about.svg` with your own portrait and candid photos. Either keep the same SVG filenames by creating equivalent SVG assets, **or (recommended)** upload `caroline-hero.jpg` and `caroline-about.jpg` to `assets/` and change the two `src=` values in `index.html` to the JPG filenames. Optimize photos for web, ideally under ~400 KB each, and update alt text to describe the real images.
3. **Client voices:** The section is intentionally a future placeholder. Do not publish invented client testimonials. Add genuine feedback only with explicit client permission and agreed attribution.
4. **Services and credentials:** Review availability, package format, reduced-fee wording, and credential statements before launch. No prices or unearned certifications are claimed.
5. **Privacy:** If you later integrate a form, analytics, scheduling, or email marketing, add an appropriate privacy notice and review data collection practices.

## Deploy

GitHub repository → Settings → Pages → Deploy from branch → `main` → `/ (root)`. Make sure the `assets` folder sits next to `index.html`.

## Notes

- The philosophy artwork is abstract on purpose; detailed coaching worksheets, six-lens diagrams, and facilitation tools are not included.
- The site uses Google Fonts online with local fallbacks.
- The Curiosity Corner contains short original reflections, not complete blog articles or functioning article links.
- For accessibility, test keyboard navigation, contrast, and responsive layouts after inserting your photos.
